# firmware

Firmware and topology files bundled into the audio kexts. None of this is
NextBSD's code, and none of it is covered by this repository's LICENSE.

Each vendor's files go in their own directory together with that vendor's
licence, unmodified, and with a note of where and from which release they were
taken. The first will be Intel's Sound Open Firmware binaries and topologies from
[thesofproject/sof-bin](https://github.com/thesofproject/sof-bin) (BSD-3-Clause
notice with a limited patent grant, `LICENCE.Intel`).
